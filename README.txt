ФИНАНСЫ ПРОЕКТОВ — NETLIFY, ВЕРСИЯ 4

СТРУКТУРА:
Проект
 ├── Подпроект 1
 ├── Подпроект 2
 └── Подпроект 3

Например:
Стройка
 └── Женя

Субаренда
 └── Олонецкая

В КАЖДОМ проекте можно добавлять сколько угодно подпроектов.
Новый проект создаётся отдельно.
Подпроект всегда создаётся внутри выбранного проекта.

Это версия без облака. Данные сохраняются в браузере.
