ПРОЕКТЫ — финальная версия

Для GitHub Pages нужны файлы:
- index.html
- style.css
- app.js
- manifest.webmanifest
- icon.svg

README.md и README.txt не влияют на работу приложения.

Изменения в этой версии:
- новый проект создаётся только с названием, без выбора «Стройка / Субаренда»;
- внутри каждого проекта можно создавать подпроекты и уже там выбирать тип;
- стройка: Смета, Приход, Расход;
- в приходе стройки нет поля «От кого»;
- единая смета считает себестоимость, цену для клиента и маржу;
- расходы можно пополнять отдельными записями с датой, категорией, описанием, местом и суммой;
- субаренда считает весь приход, все расходы и чистую прибыль;
- просроченные платежи подсвечиваются красным;
- по каждому проекту суммируется результат всех подпроектов и показывается плюс/минус;
- приложение при добавлении на главный экран называется «ПРОЕКТЫ».
